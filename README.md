# GitHub Analyzer Pro V2
Python-based GitHub Profile Analyzer using GitHub API with repository filtering, CSV export, stars tracking, and language analysis.

A Python-based GitHub profile analyzer that fetches real-time user data using GitHub API.

## Features
- Fetch GitHub user profile
- Display followers and repository count
- Show repository stars
- Filter repositories by language
- Export data to CSV
- Error handling for invalid users

## Tech Stack
- Python
- Requests
- CSV
- GitHub REST API

## How to Run

1. Install requests:
pip install requests

2. Run:
python github_analyzer_pro.py

3. Enter GitHub username
